用户协议

版本：2026-08｜更新日期：2026年8月21日｜生效日期：2026年8月21日

本协议由你与深圳市译识编元科技有限公司（以下简称“我们”）共同订立，适用于 WV Chat 应用、网站及相关服务。请在注册、登录和使用前认真阅读，特别关注账号注销、用户内容、预约服务、责任限制和争议解决条款。

当你主动勾选同意并注册、登录或使用 WV Chat，即表示你已阅读、理解并接受本协议及 《隐私政策》。如果你不同意，请不要注册、登录或使用服务。

一、服务内容与范围

WV Chat 提供以即时通讯为核心的服务，包括：

  • 账号注册、登录、个人资料和安全设置；
  • 好友、黑名单、群组、单聊和群聊；
  • 文字、图片、视频、语音、文件、表情和名片；
  • 语音通话、视频通话（通话期间支持悬浮窗显示，可在使用其他应用时继续管理通话）、扫码及消息通知；
  • 预约服务、预约记录、核销状态和积分账本；
  • 我们不时提供并在应用内明确展示的其他辅助功能。

具体功能会因操作系统、设备、地区、网络、账号状态及版本配置而不同。尚未在正式版本中启用的功能不构成我们向你的承诺。

二、账号注册、使用与安全

  • 你应使用合法方式注册，并确保提交的用户名、昵称、头像、手机号、邮箱等资料真实、准确、合法，不得冒充他人或使用侵害他人权益的信息。
  • 你应妥善保管账号、密码、验证码及登录设备，不得转让、出租、出借、售卖账号。通过你的账号实施的操作，在有相反证据前视为由你本人实施。
  • 发现账号被盗、密码泄露或异常登录时，应立即修改密码并联系我们。因平台安全缺陷造成的损失，我们依法承担相应责任；因你主动泄露或明显保管不当造成的损失，由责任方依法承担。
  • 你不得恶意注册、批量注册、使用自动化工具操控账号，或规避平台安全、内容治理及访问限制。

三、用户内容与授权

“用户内容”是指你通过 WV Chat 创建、上传、发送或分享的昵称、头像、文字、图片、语音、视频、文件及其他内容。你保留对合法用户内容依法享有的权利，并对内容真实性、合法性及后果负责。

为完成发送、同步、展示、缓存、备份、内容安全检查、举报处理和故障恢复，你授予我们一项非独占、仅限提供及维护 WV Chat 服务所必要范围和期限的处理许可。我们不会据此取得用户内容的所有权，也不会将其用于与服务无关的广告营销。

你上传涉及他人个人信息、肖像、声音、作品或其他权益的内容前，应确保已取得合法授权。收到有效的侵权或违法投诉后，我们可依法核实、限制展示、删除或采取其他必要措施。

四、用户行为规范

你不得通过 WV Chat 制作、复制、发布、传播、存储或协助传播以下内容或实施以下行为：

  • 违反法律法规、危害国家安全、公共安全或社会公共利益的内容；
  • 淫秽色情、赌博、毒品、暴力恐怖、自残、仇恨歧视、欺凌、骚扰或威胁内容；
  • 诈骗、虚假交易、恶意营销、垃圾信息、违法广告或诱导分享内容；
  • 侵犯他人隐私、个人信息、名誉、肖像、著作权、商标权、商业秘密等合法权益的内容；
  • 冒充他人、伪造身份、散布虚假信息或以其他方式误导用户；
  • 病毒、恶意代码、钓鱼链接，或攻击、干扰、绕过、反向工程服务及安全措施的行为；
  • 利用账号、群组、预约或积分机制刷量、作弊、套利、扰乱正常运营秩序的行为；
  • 其他违反法律法规、本协议或合理社区安全要求的行为。

五、内容安全、举报与屏蔽

为保护用户安全，WV Chat 会对部分文字内容进行必要的违法和不良信息识别、拦截或替换，并保存必要的违规记录。该措施不能保证识别全部违规内容，用户仍应谨慎判断陌生人、链接、转账或线下邀约。

  • 你可在联系人详情等应用内入口举报涉嫌色情低俗、骚扰辱骂、广告欺诈、违法或其他不当行为，并可补充说明；
  • 你可将骚扰或滥用服务的用户加入黑名单，限制其继续联系；
  • 我们会根据举报内容、证据和风险程度进行核查，并在合理时间内采取警告、内容限制、禁言、冻结、注销或向主管机关报告等措施；
  • 紧急人身安全风险请优先联系当地公安、急救或其他紧急服务机构。

六、预约服务与积分

  • 预约页面展示的服务类型、门店、时间、人数、核销条件及其他说明构成该次预约的重要规则。你应提交真实有效的联系人和联系电话，并按约到店或及时取消。
  • 服务能否提供可能受门店营业安排、名额、设备、天气、公共事件等因素影响。发生变更时，我们或实际服务提供方会尽合理努力通知并提供可行的处理方案。
  • 如预约涉及线下付款、退款、发票或其他交易，应以预约页面和实际服务提供方公示的规则为准。当前积分主要用于服务记录或按规则扣减，不是法定货币，不可提现、买卖或擅自转让。
  • 因你填写错误、未按约到场、违反门店规则造成的影响由相应责任方承担；因我们或服务提供方原因未能履约的，依法依约处理。

七、第三方服务

WV Chat 使用极光推送和 Apple 系统推送服务发送通知。第三方服务由相应主体独立提供，其服务条款和隐私政策适用于你与该第三方之间的关系。我们会依法审慎选择合作方并承担自身应负责任，但无法控制第三方独立运营环节。

第三方 SDK、数据类型和处理目的详见 《隐私政策》。若未来增加新的第三方服务并涉及个人信息，我们会依法更新说明并在需要时征得同意。

八、个人信息保护

我们重视个人信息保护。关于个人信息的种类、权限、第三方 SDK、存储期限、账号注销及你的权利，请阅读 《隐私政策》。隐私政策是本协议的重要组成部分。

九、账号注销

你可通过 WV Chat“设置 → 注销账号”，验证当前密码后直接发起注销，也可通过本协议末尾邮箱联系我们。注销后账号会停用，主要身份资料会清除或匿名化，且无法使用原凭据继续登录。为维护其他用户已形成的会话、履行法定义务、审计或处理争议，部分历史消息和记录可能在必要期限内保留并限制使用，具体见《隐私政策》。

十一、服务变更、中断与终止

我们可能因版本升级、设备适配、安全风险、法律要求或业务调整而变更服务。对可能实质影响你权益的变更，我们会通过应用内提示、公告或其他合理方式通知。

十二、责任限制

我们按照适用法律在合理能力范围内提供服务，不对超出合理控制范围的网络波动、设备兼容、第三方故障或不可抗力作绝对无中断保证。本条不排除或限制因我们故意、重大过失、侵犯人身权益或法律规定不得限制的责任。

用户之间的聊天、文件和线下互动由参与者自行判断并承担相应责任。请勿轻信陌生人，不要发送密码、验证码、身份证件、银行卡等敏感信息；涉及违法犯罪的，应及时保存证据并向有关机关报告。

十三、违约处理

如你违反法律法规、本协议或侵害他人权益，我们可根据行为性质和风险，在依法核实后采取提醒、限制发送、屏蔽内容、禁言、暂停功能、冻结或注销账号等措施。必要时我们会保存记录并向主管机关报告。你对处理结果有异议，可通过联系邮箱申诉。

十四、未成年人

WV Chat 主要面向成年人。未满十八周岁的用户应在监护人同意和指导下使用；未满十四周岁的儿童应由监护人完成同意。未成年人不得发送不适龄内容、与陌生人进行高风险线下活动或参与不适当交易。监护人可联系我们协助处理未成年人账号和信息。
